=== AUDIOFM - FM notes and instruments ===

The playable layer over the YM2151: eight FM channels, addressed by note
and instrument rather than by register. None of THAT is written.

What does work is SOUND, over VERA's PSG -- a different and much simpler
sound chip, which happens to live in VRAM and so needed no register
protocol at all. This page mattered most for a beginner's BASIC because
a child should be able to make a noise in one line, and none of the
register poking in HELP AUDIOYM is that line. SOUND is that line; the FM
voices below would make it a good one.

[x] SOUND voice,hz,volume - play a tone on one of VERA's 16 PSG voices.
    Voice 0-15, frequency in Hz, volume 0-63, both channels, a 50% pulse.
    It keeps sounding until silenced, so SOUND v,0,0 is how a note ends.
    NOT the YM2151: the PSG is simpler, it is VRAM rather than registers
    with a busy flag, and it was therefore the one that could be written
    first. The FM voices below are still to come.
[x] FMINIT - silence every channel and load one usable instrument on all
    eight. Without it the chip powers up with every operator at zero
    output level and total silence, which reads as "FM is broken" rather
    than "FM needs an instrument". The patch is not a good sound. It is
    an audible one.
[x] FMNOTE ch,note - key a note on. Semitones, twelve to the octave, 48
    near middle C. The chip does not take semitones: it wants an octave
    and a note code whose four-bit field SKIPS the values 3, 7, 11 and
    15, so the twelve codes are a table rather than arithmetic. Getting
    that wrong transposes everything above D by a semitone, which sounds
    like bad tuning rather than like a bug.
[x] FMOFF ch - key it off. A note held is a note that keeps playing.
[x] FMVOL ch,vol - channel volume 0-127, loudest at 127. The chip has no
    volume, only a per-operator attenuation where 0 is loudest, so this
    inverts; and it writes only the carriers, because writing a
    modulator would change the timbre instead of the loudness.
[ ] FMINST ch,n - select one of a built-in instrument set.
[ ] FMLOAD file$ - load an instrument bank from the card.
[x] FMPAN ch,lr - 1 left, 2 right, 3 both.
[ ] PLAY s$ - a music string, the classic BASIC way: notes, octaves,
    lengths and rests in one argument.

Two things to settle before writing any of it:

Timing. SOUND with a length has to end the note, and BASIC has no clock
of its own here. Either it blocks for the duration - simple, and wrong
for a game - or a VSYNC handler ages the voices. The kernel's KIRQ_VSYNC
slot is the hook, but nothing in SuperBasic installs handlers yet.

Volume shadowing. FMVOL's attenuation is applied when it is set, so a
later raw YMPOKE straight at a total-level register ($60-$7F) overrides
it until the next FMVOL or FMINST. Mixing the two layers needs that
documented, or it reads as a bug.
