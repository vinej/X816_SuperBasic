=== AUDIOPCM - sampled sound through VERA's FIFO ===

VERA has a 4 KB audio FIFO taking signed 8- or 16-bit PCM, at three
registers inside its block at $9F20-$9F3F. Nothing in SuperBasic drives
it yet.

[x] PCMVOL v - output volume 0-15. Read-modify-write, because the same
    byte carries the sample format.
[x] PCMMODE bits,stereo - 8 or 16 bit, 0 mono or 1 stereo.
[x] PCMRESET - empty the FIFO and stop. Bit 7 alone resets; bits 7 and 6
    together mean LOOP on this hardware, not "reset harder", so the two
    must never be set at once.
[x] PCMOUT b - push one sample byte.
[x] PCMFREE - 1 while the FIFO has room, 0 when it is full. Takes no
    parentheses, which needed a tokenizer fix of its own (tokens.s,
    TKPREVFN). WHILE PCMFREE ... PCMOUT ... WEND is the feeding loop.
[ ] PCMCTRL n - $9F3B. Volume 0-15, bit 4 stereo, bit 5 16-bit, bit 7
    resets the FIFO. Reading it back gives two bits the write side has no
    use for: bit 7 full, bit 6 empty.
[x] PCMRATE n - $9F3C. 0 stops, 128 is about 48 kHz, and the step is
    25000000/(512*128), roughly 381.5 Hz. Anything above 128 is read by
    the hardware as 256-n, which is a wrap and not a clamp, so it is
    refused here instead.
[ ] PCMPUT b - $9F3D. Push one sample byte; dropped if the FIFO is full.
[ ] PCMFULL - true when it cannot take more.
[ ] PCMEMPTY - true when it has run dry, which is the one a feeder
    actually wants: by then the sound has already stopped.
[ ] PCMPLAY file$ - the statement most people want. Stream a sample off
    the card without the program having to feed it.

A paced feeder in BASIC, once the statements exist, is the loop you would
expect - push while not full, top up when not empty. Doing that from
interpreted BASIC will not keep up at 48 kHz for long, which is the
honest reason PCMPLAY belongs on the list: the refill wants to be an
AFLOW interrupt handler in assembly, and the kernel already reserves the
slot for it (KIRQ_AFLOW, slot 3). IRQ 3,addr installs one and switches
the source on for you - HELP SYSTEM. This is a case where the machine
code is the point and the deferred BASIC handlers are no use: a FIFO
that has to be refilled before it empties cannot wait for the
interpreter to finish the statement it is on.

Where the samples come from matters more here than anywhere else on
these pages. A second of 8-bit mono at 22 kHz is 22 KB - larger than the
whole BASIC program space is likely to be, and far too large to sit in a
DATA statement. Samples belong on the card and want streaming, so this
page depends on HELP FILE landing first.
