=== VIDEO - VRAM, screen modes and the font ===

VERA's 128 KB of video RAM is NOT in the CPU address space. It is reached
through a port: set an address in $9F20-$9F22, then read or write $9F23,
and the address auto-increments. Everything on the graphics pages - tiles,
sprite pixels, the palette, the font - lives behind that port.

[ ] VPOKE addr,value - write a byte of VRAM.
[ ] VPEEK(addr) - read one back.
[ ] VADDR addr - point the port once, then stream. Worth having as well
    as VPOKE: a bulk copy that re-sends the address for every byte does
    three writes where it needs one.
[ ] SCREEN mode - 0 the text console, 128 the 320x240 bitmap. The X16's
    other text modes (80x30, 40x60, 40x30) are scale settings and could
    follow. HELP GRAPHIC for the VERA2 alternative at 640x480.
[ ] BORDER c - the border colour.
[ ] CURSORX / CURSORY - read the cursor position back. The kernel has
    CON_GETXY and SuperBasic already calls it internally; there is no
    keyword for it.
[ ] SCROLLX n / SCROLLY n - HARDWARE scroll of a layer, 0-4095. Free
    smooth scrolling with no redraw at all, which is the difference
    between a playable game and a slideshow on a machine this size.

--- the font ---

The console is VERA layer 0 and its font is ordinary VRAM the kernel
filled at boot. There is NO character ROM, so unlike the C64 or the X16
there is no ROM number to select - a font is an address, and anything you
can write is a font. This is the redefinable-character-set feature, and
for a beginner's BASIC it is one of the most rewarding things on any of
these pages: it is how you get a game's tiles and a custom alphabet
without touching sprites or bitmaps.

A font is 256 glyphs of 8 bytes = 2 KB, on a 2 KB boundary. A glyph is 8
bytes, one per scanline, top first, bit 7 leftmost. Codes are CP437 and
the tile index IS the character code - no $20 bias, so 65 really is "A".
The kernel's font sits at VRAM $4000, with the tilemap below it at
$00000-$03FFF; $4800 is the next free slot.

[ ] CHARSET addr - point the console at a font.
[ ] GLYPH addr,n,d0,d1,d2,d3,d4,d5,d6,d7 - redefine character n. Eight
    bytes is awkward as arguments; reading them from DATA is probably the
    friendlier form.
[ ] GLYPHGET addr,n - read a glyph back.
[ ] FONTCOPY src,dst - duplicate 2 KB of font.

Copy before you edit. Editing the font at $4000 edits the one being drawn
with, including the message telling you what went wrong, and there is no
way back short of a reboot. Copy it to $4800, edit that, then point
CHARSET at it - and CHARSET $4000 typed blind still puts it back.
